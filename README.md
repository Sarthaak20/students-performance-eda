# Students Performance EDA

An exploratory data analysis notebook using Python, Pandas, NumPy, and Matplotlib.

## Dataset
- Kaggle: https://www.kaggle.com/datasets/spscientist/students-performance-in-exams
- The notebook downloads a public CSV mirror for convenience.

## Run
1. Open `students_performance_eda.ipynb` in Google Colab or Jupyter.
2. Run all cells from top to bottom.
3. Review the charts and replace the findings prompts with your own observations.
4. Push the notebook and this README to a public GitHub repository.

## Analysis included
- Dataset shape, data types, memory usage, head and tail
- Missing-value counts, percentages, bar chart, and heatmap
- Numeric summary statistics and categorical value counts
- Six visualisations with interpretation prompts
- Final findings checklist
